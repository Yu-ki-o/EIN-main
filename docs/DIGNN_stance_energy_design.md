支持反对关系能量场：DIGNN 节点结构表示设计

日期：2026-10-12。状态：文献与设计稿。本文中的正对角关系映射、多尺度场值、
局部能量和源残差现已实现于 `model/DIGNN.py`；完整数据集训练尚未进行。
实际接口和运行参数见 [DIGNN 使用说明](DIGNN.md)。本文中一般矩阵映射、
不同迭代步快照及能量随机基准仍是后续扩展。

建议将模块定义为“以支持、反对关系为条件的有源能量最小化结构编码器”。先从现有边立场构造双通道证据源，再通过一个明确、有下界的图能量函数求场响应，最终把场值、局部能量及源残差编码成节点向量。能量是学习的结构兼容性代价，不是物理能量，也不直接表示事实真假或语言情绪强弱。

**1. 文献依据**

- [Graph Neural Networks Inspired by Classical Iterative Algorithms，ICML 2021，TWIRLS](https://proceedings.mlr.press/v139/yang21g.html)：从“输入保真加图正则”的能量出发，将优化迭代展开为可微图网络。正文 [第 2 节](https://arxiv.org/html/2103.06064v4#S2)包含二次能量、解析解和非负约束对应的近端更新。
- [Neural Sheaf Diffusion: A Topological Perspective on Heterophily and Oversmoothing in GNNs，NeurIPS 2022](https://papers.nips.cc/paper_files/paper/2022/hash/75c45fca2aa416ada062b26cc4fb7641-Abstract-Conference.html)：用边两端各自的线性映射表达局部兼容性。本设计借鉴这种平方残差形式，用父/子角色与 support/deny 决定映射，不复现其完整算法。
- [Unsupervised Joint k-node Graph Representations with Compositional Energy-Based Models，NeurIPS 2020](https://papers.neurips.cc/paper_files/paper/2020/hash/cba0a4ee5ccd02fda0fe3f9a3e7b89fe-Abstract.html)：以可组合能量学习联合图表示，可作为概率能量模型的参考。下面先采用能量最小化编码，不需要为图建立生成模型。
- [A Generalized Tikhonov Layer for Interpretable-by-design Graph Neural Networks，2026 预印本](https://arxiv.org/abs/2605.28578)：其传播是广义图 Tikhonov 能量的解，并用输入保真系数及图滤波参数解释特征和结构贡献。这里不将作者的架构或性能结论直接移植到谣言检测。

这些工作支持“明确能量函数、可微求解、用解作为表示”的路线。双通道、关系角色和能量诊断是本任务的具体设计；是否形成足够的方法创新，还需要相近方法及任务基线的实证比较。

**2. 必须区分场源、场值和能量**

场源 b_v：节点直接收到的支持/反对关系量。场值 phi_v：这些证据在传播拓扑及关系兼容性作用下得到的连续响应。能量 E：场值偏离场源、或不能符合邻域关系兼容性的代价。

因此，高支持场值并不必然对应高支持关系能量。一个大而均匀的支持环境，可以有很大的支持场值和很小的空间变化能量。双方关系同时丰富，也可能形成均匀场，不能仅凭小 Dirichlet 能量判定“无争议”。场值和能量都需要保留。

边 p → c 表示 c 回复 p，标签 r_pc 表示 c 对 p 的态度。它不是 p 对 c 的态度，也不能直接当作 c 对源帖的态度。输入优先使用匹配的 directed_edge_index/directed_edge_stance。

已有 model/BiGCN_UncertaintySemanticChange.py 的 evidence_energy 是对端点隐表示及其差值使用 sigmoid MLP 的门控。它可描述学习到的权重，但没有单独定义需要对场变量求解的能量泛函。当前方案补充这种能量和求解机制。

**3. 双通道局部证据源**

\[
S_v=\sum_{c\in children(v)}\mathbf1[r_{vc}=S],\qquad
D_v=\sum_{c\in children(v)}\mathbf1[r_{vc}=D].
\]

第一版使用固定、可解释的源：

\[
b_v=[\log(1+S_v),\log(1+D_v)]\in\mathbb R_+^2.
\]

也可以用原始数量作为消融。不能只用 S-D，否则没有反馈与双方大量共存都可能给出零源。没有有效标签的回复不默认是支持；另外保留全部回复数量、有效标签覆盖率及邻域存在标记。根/自身对父帖的角色和深度单独输入后续编码器，根不人为赋成 support。

先用固定双通道源，可以明确追踪输入和场响应。若以后让 MLP 自由生成高维源，高维各分量将成为潜在结构变量，不能再逐维宣称它们就是支持和反对强度。

**4. 基线：锚定的双通道 Dirichlet 场**

\[
E_\tau(\Phi)=\frac12\sum_v q_v\|\phi_v-b_v\|^2
+\frac\tau2\sum_{\{u,v\}\in E}w_{uv}\|\phi_u-\phi_v\|^2.
\]

q_v >= q_min > 0，w_uv >= 0。第一版固定 q_v = 1、w_uv = 1；另一版本可以用已知覆盖率调整 q，但覆盖率不是语言置信度。

若不施加非负约束，令 Q = diag(q)，L_w 为无符号加权拉普拉斯：

\[
\Phi^*=(Q+\tau L_w)^{-1}Q B.
\]

对该标量通道共享的普通拉普拉斯，B >= 0 时解也非负。Q 的正下界保证严格凸性、唯一解，并使能量不通过所有节点变成常数零来平凡最小化；源全部为零的无标签事件仍可合理得到零场，角色和缺失标记继续区分它的状态。

这组源和图平滑本身接近已有图正则/扩散方法，应作为能量方法的基线，不单独声称创新。

**5. 任务版本：父子角色条件化的关系能量**

给每种关系 r in {S,D,U} 定义父侧映射 A_r^P 和子侧映射 A_r^C。对 e = (p,c)：

\[
\delta_e=A_{r_e}^{P}\phi_p-A_{r_e}^{C}\phi_c.
\]

定义：

\[
\boxed{E_{\theta,\tau}(\Phi;G,R)
=\frac12\sum_v q_v\|\phi_v-b_v\|^2
+\frac\tau2\sum_{e=(p,c)}w_e\|\delta_e\|^2.}
\]

节点场变量仍是双通道。映射由任务训练学习，标签只选择哪一组映射；不规定 A_D = -I 或固定通道交换，因而没有预设 DD 必须转换成源帖支持。

第一版可以使用非零有界对角映射：A_r^role = diag(exp(c*tanh(a_r^role)))，初始化为 I，c 为固定边界。这样参数少、通道仍可解释，避免所有关系映射同时收缩成零。完整版允许有界 2x2 映射表达通道关联，必要时加入非负场约束 Phi >= 0。一般映射下，无约束解不保证非负，不能直接把其每个数解释为证据密度。

为满足真正的单一能量解释，q、w 和 A 在一次场求解过程中应固定。它们可以由训练参数或当前图的固定结构描述量产生。若每一步根据 phi 重新用任意 MLP 改映射，原先关于固定二次能量的收敛结论就不再适用。

令 D_theta 是把全部边残差堆叠起来的线性算子，则关系拉普拉斯为 L_theta = D_theta^T W D_theta，半正定。无约束解满足：

\[
(Q\otimes I_2+\tau L_\theta)\operatorname{vec}(\Phi^*)
=(Q\otimes I_2)\operatorname{vec}(B).
\]

因为 q_min > 0，该系统严格正定。非负约束问题也严格凸并有唯一解。父侧和子侧映射不同会引入方向角色；如果二者一直相同且权重对称，该部分会退回无向兼容性，方向并不会因公式中写了箭头就自动得到利用。

**6. 可微求解及训练**

不构造整个批次的稠密矩阵。从 Phi^(0) = B 出发，用边 gather/scatter 计算能量梯度，展开固定步数：

\[
\Phi^{(t+1)}=\Pi_{\mathbb R_+^{N\times2}}
\left[\Phi^{(t)}-\eta\nabla_\Phi E_{\theta,\tau}(\Phi^{(t)})\right].
\]

非负投影对应 ReLU。一个保守的 Hessian 谱上界为：

\[
C=\max_v\left(q_v+2\tau\sum_{e\ni v}w_e\|A_{v,e}\|_2^2\right).
\]

使用 eta <= 1/C 可以保证固定能量的下降；学习步长时可以令 eta = sigmoid(a_eta)/C。该界是通过对每条边的两端平方残差应用二次上界得到的，不需要求解全图谱。

也可以使用预条件梯度或稀疏共轭梯度，但其梯度计算、误差容忍度和非负约束处理应保持一致。训练通过展开的求解器把事件分类梯度传回关系映射等参数。

内层求 phi 是能量最小化；外层学习 theta 仍由谣言分类目标驱动。不要额外把可训练的总能量无约束地压到零，否则可能鼓励映射、耦合强度或源退化，而不是学习有用的结构。

**7. 节点特征：场值、局部能量和分量响应**

对每个 tau 保留：

1. phi_v^S、phi_v^D：双场响应。
2. phi_v-b_v：与本地源的偏离。
3. 按 support/deny/unknown、父/子角色分组的边能量。
4. b_v 和有效标签/位置标记：保留输入量与缺失状态。

边能量的一半分配给每个端点。对于关系 r：

\[
e_v^{out,r}=\frac\tau4\sum_{e=(v,c),r_e=r}w_e\|\delta_e\|^2,
\qquad e_v^{in,r}=\frac\tau4\sum_{e=(p,v),r_e=r}w_e\|\delta_e\|^2.
\]

对所有节点、方向和类别求和可还原全部关系能量。可以同时保留 sum 与 per-edge mean、相应边数，避免把更多回复直接解释为更强的不兼容。源保真能量另为 e_v^source = q_v||phi_v-b_v||^2/2。

如果需要“压力/通量”特征，可以保留源恢复分量 q_v(b_v-phi_v)，及单条边对父、子节点施加的关系梯度分量：

\[
f_e^{P}=-\tau w_e(A_r^P)^T\delta_e,
\quad f_e^{C}=+\tau w_e(A_r^C)^T\delta_e.
\]

它们是能量梯度贡献，不是守恒的物理电流；一般角色映射下，两端的向量不必等大反向。无约束平衡点的总梯度为零，所以不把总梯度本身当作有区分度的节点特征。非负约束的边界点还需要考虑约束的 KKT 分量。

可以选择几个耦合尺度 tau_k，或在同一能量的不同迭代步读取响应。不同 tau 的平衡响应与同一 tau 的有限步轨迹是两种实验，不能混称为相同的尺度。第一版可从同一能量的 3/6/12 步快照开始，另比较不同 tau 下的充分求解结果。

最终：

\[
h_v^{(0)}=\operatorname{MLP}([b_v,p_v,
\phi_v^{(\tau_1)},e_v^{(\tau_1)},\ldots,
\phi_v^{(\tau_K)},e_v^{(\tau_K)},\text{source residuals,masks}]).
\]

p_v 为独立的根/自身对父帖的角色、深度等编码。随后沿用 DIGNN 的 GIN 和事件读出。不是只把一个节点能量标量送给 GIN。

**8. 小图核对：场值相同，但局部能量不同**

采用先前设计稿中的七节点配对树：根 v 有两个子节点，每个子节点有两个叶节点。两条根边都为 S。图 A 的两条分支末端标签分别为 SS、DD；图 B 的每条分支末端标签均为 SD。此处 SS/DD/SD 是同一父帖收到的两条并行关系，不是路径符号乘积。

两图无符号拓扑相同，根一跳均 S=2,D=0，根二跳均 S=2,D=2，二跳路径计数均 SS=2,SD=2。为取得解析数值，以下使用原始接收数量作为源，Q=I、w=1、tau=1、所有关系映射为 I，即第 4 节基线。

| 量 | 图 A：分支分离 | 图 B：分支交错 |
| --- | ---: | ---: |
| 全图支持源数量总和 | 4 | 4 |
| 全图反对源数量总和 | 2 | 2 |
| 根支持场值 | 8/7 | 8/7 |
| 根反对场值 | 2/7 | 2/7 |
| 根关系能量（相邻边各分配一半） | 94/441 = 0.2131519274 | 5/49 = 0.1020408163 |
| 全图最小总能量 | 64/21 = 3.0476190476 | 12/7 = 1.7142857143 |

这个例子说明仅取根的场值仍可能忽略分支组织；邻域场的平方变化能量补充了均值响应遗漏的分布信息。它不证明高能量一定有害、表示语义冲突，或完整模块优于 GIN。共享 MLP/GIN 也可能从子节点源中学到这个差异，因此必须与相同输入的基线比较。

数值核对使用固定二次能量的双通道梯度下降，步长 0.1，400 步。两种情况下每一步能量均未增加；最后最大梯度分量均约 8.88e-16；表中局部能量与解析值误差小于 1e-10。这是优化及计算核对，不是数据集效果验证。

**9. 与先前分支组织模块的关系**

先前设计显式计算分支分离偏离量 Delta，本方案学习证据源在拓扑中的平衡响应及关系残差。两者可以先独立比较，再研究把 Delta 用作固定关系权重的条件量。第一版不把所有统计和能量诊断都堆叠成一个很大的模型，以免无法判断增量来自何处。

若对能量再做标签随机基准校正，需要重新计算扰动后的源及关系算子。能量是二次函数，因此“观察能量减期望能量”不等于“观察源减期望源再求能量”。可以在同一拓扑、同层 S/D 总量约束下做少量置换估计基准，作为后续方法与解释实验；此前 kappa_0 的闭式公式不能直接当作能量的零模型期望。

**10. 不适合直接采用的形式**

纯 signed Dirichlet 能量 sum_S||h_p-h_c||^2 + sum_D||h_p+h_c||^2 在树上可通过节点符号切换达到零关系能量，并暗含路径符号组合。没有证据源或其他约束时，它不足以刻画当前标签的组织方式。标准 signed Laplacian 在固定无符号树上的谱也不依赖 signing，见 [有符号树谱的相关结论](https://www.aimspress.com/aimspress-data/math/2023/3/PDF/math-08-03-354.pdf)。该结论不否定带源、锚点、关系角色或其他约束的有符号模型。

把 deny 写成负二次项 -lambda||h_p-h_c||^2 则可能使能量没有下界。正的平方关系残差避免这种问题。也不宜把字段名、MLP 输出或均衡比例直接称为物理能量。

若未来希望建立概率形式 p_theta(Phi|G,R) proportional to exp(-E_theta(Phi;G,R))，还需要明确其概率训练目标及归一化处理；这是另一层建模，不是现有事件分类损失自动得到的结果。

**11. 接入与必要消融**

建议新增 StanceEnergyEncoder，输出初始 nodes [N,H]、固定 raw_descriptors 和 detached diagnostics。DIGNN 的六维构造与固定 Linear(6,H) 输入层改为该模块，保留文本分支、图级融合及训练接口。当前 energy_head 不作为物理证据强度的教师。

若启用结构重建，目标应采用固定的场源与角色/覆盖率等原始描述量，不将可训练场值、映射相关能量当作无条件自重建目标。当前基础配置辅助权重为零，可先保持一致比较节点表示。HSIC 的权重另作消融，因为边标签由文本生成，两分支不具备统计独立性的先验保证。

比较：六维 DIGNN；相同支持/反对源加 MLP/GIN；普通锚定能量场；父子角色和关系条件能量场；加入节点局部能量与源残差的完整版。控制参数量、有效传播范围和算力预算。还应比较场值-only 与场值+能量、关系共享与区分、方向角色共享与区分、单尺度与多尺度，以及固定源与可训练源。

只有这些比较显示增量，才能把贡献定位为“从支持反对关系的强度描述，推进到关系兼容性及多尺度能量响应的节点结构学习”。Dirichlet 能量、sheaf 映射和迭代展开都已有研究，不能分别宣称首创。
