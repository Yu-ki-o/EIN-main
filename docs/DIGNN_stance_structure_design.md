分支条件化的立场结构编码：DIGNN 节点表示设计稿

日期：2026-10-09。状态：方法设计与解析公式核对，尚未实现模型或开展分类实验。

建议把研究问题定义为：在传播拓扑、各层支持/反对总量相同的情况下，支持和反对如何沿回复关系关联，如何在不同讨论分支中分配，能否为谣言检测提供额外信息？模块只输入传播边、边立场、事件归属和根位置，输出每个节点的结构表示，不直接读取文本向量或谣言真假标签。标签本身由文本生成，因此该分支应称为立场关系结构分支，而不是纯拓扑分支。

[Network motifs: simple building blocks of complex networks](https://pubmed.ncbi.nlm.nih.gov/12399590/)提出了把模式出现量与随机基准比较的经典思路。以下局部条件期望公式是针对当前传播树与硬标签的推导，不应写成上述论文已有的公式。

近期的 [TopoSIGN：Signed Graph Pre-Training and Prompt Learning，2026](https://arxiv.org/abs/2609.25722)组合了磁有符号拉普拉斯编码与 Dowker 复形持久同调，用于有符号图迁移学习。这说明有符号拓扑编码已有更复杂的研究路线；本设计选择与父帖回复语义对应、可解析、可在线性遍历中计算的节点局部结构。

另一个选型依据是传播树的无环性质：在标准无向有符号拉普拉斯 L = D - A_sigma 下，给同一棵树改变边符号不会改变拉普拉斯谱，见 [Laplacian integral signed graphs with few cycles](https://www.aimspress.com/aimspress-data/math/2023/3/PDF/math-08-03-354.pdf)第 3 节。因此，仅使用该谱无法表达树上不同的 S/D 排列。此结论不排除包含锚点、方向、属性或完整特征向量的其他谱编码方案。

**2. 图与标签的语义**

输入是以源帖为根的有向传播树。边 v → u 表示 u 回复 v，r_vu = S/D 表示 u 支持/反对 v。对非根节点而言，入边标签表达自身对父帖的态度，不是自己收到的反馈，也不一定是对源帖的态度。

每个节点 v 的直接子节点 u 定义一个局部分支：以 u 为根的后代子树。相对距离 k 的事件，是距 v 恰好 k 条传播边的后代所对应的最后一条回复边。k = 1 是对 v 的直接反馈；k > 1 是 v 周围的回复关系环境。

同一分支内两条关系都是 deny，并不意味着它们反对同一个命题。下文“交错”“分离”描述关系标签的结构分布，不表示心理态度、真假、群体冲突或用户阵营。

**3. 多尺度立场量：保留量、比例和缺失状态**

令 B 为无符号父 → 子邻接算子，B_S/B_D 是按有效标签分出的算子。对所有节点同时计算：

\[
S^{(1)} = B_S \mathbf 1,\quad D^{(1)} = B_D \mathbf 1,
\qquad S^{(k)} = B S^{(k-1)},\quad D^{(k)} = B D^{(k-1)}.
\]

同时计算全部事件数 N^(1) = B 1、N^(k) = B N^(k-1)。令 M = S + D，则标注覆盖率为 M/N，N = 0 时置零，另保留 N > 0 的存在标记。缺失标签不计为支持或反对。

每个节点、每个尺度使用确定性描述量：

\[
\rho_v^{(k)} = [\log(1+S),\log(1+D),\mu,c,\mathrm{coverage},\mathrm{exists}],
\quad \mu = (S-D)/M,\quad c = 4SD/M^2.
\]

M = 0 时 mu、c、coverage 置零。c 是双方关系共存程度；它不是语义冲突强度。数量项用于区分 1:1 与 100:100；比例项用于区分规模相同的不同立场组成。

这种递推只累计最后一条关系的类别。没有符号乘积，没有根相对立场转换。第一版建议 K = 2，另做 K = 1、3 的消融。

**4. 关系关联：首条关系与下游关系的条件耦合**

对于 k >= 2、分支 v → u，定义分支在第 k 层的量：

\[
s_{vu}^{(k)} = S_u^{(k-1)},\quad d_{vu}^{(k)} = D_u^{(k-1)},
\quad m_{vu}^{(k)} = s_{vu}^{(k)}+d_{vu}^{(k)}.
\]

构造首尾关系矩阵：

\[
T_v^{(k)}(a,b) = \sum_{u\in children(v)} \mathbf 1[r_{vu}=a]\, x_{vu,b}^{(k)},
\quad a,b\in\{S,D\},\quad x_{vu,S}=s_{vu},\ x_{vu,D}=d_{vu}.
\]

k = 2 对应 SS/SD/DS/DD 数量；k > 2 表示首条关系与第 k 层关系的关联，中间关系被边际化，不保留完整立场序列。

为控制分支容量和立场基率，把有效首边分支内的末端标签在该尺度均匀置换，固定首边标签、容量及 S/D 总量。令 n_a 是矩阵第 a 行的和，n_b 是第 b 列的和，M_pair 为矩阵总和，则：

\[
E[T(a,b)] = n_a n_b/M_{pair},
\qquad R(a,b) = [T(a,b)-E[T(a,b)]]/M_{pair}.
\]

使用 T/M_pair 和 R 两者：前者保留观察到的关系组成，后者表示相对于此条件基准的关联偏离。R 不是因果效应或显著性检验。在全标注二分类情形下，R 的四个元素不是四个独立自由度；保留矩阵只是便于对称编码。

首边缺失的分支不进入 T。末端缺失标签也不进入 T。应保留 M_pair/M 的覆盖率，以避免把有效标签不足解释成没有关系关联。M_pair = 0 时矩阵及残差置零，附有效性标记。k = 1 的这组量置零并标记为不适用。

**5. 分支组织：双方是否出现在同一分支**

对某个 v、k >= 2，以下统计使用末端有效标签；它允许首边标签缺失，因为分支归属仍由拓扑确定。记各分支为 b，S = sum_b s_b，D = sum_b d_b，M = S + D。

观察到的一对 S/D 关系位于同一分支的比例：

\[
\kappa_{obs} = \frac{\sum_b s_b d_b}{SD},\qquad S>0,\ D>0.
\]

固定这层所有有效标签位置、各分支容量 m_b、S/D 总量，在有效位置之间均匀置换标签。其条件期望为：

\[
\kappa_0 = \frac{\sum_b m_b(m_b-1)}{M(M-1)}.
\]

定义分支分离偏离量：

\[
\Delta_v^{(k)} = \kappa_0 - \kappa_{obs}.
\]

- Delta > 0：两类关系在不同分支出现的程度高于这个条件基准。
- Delta < 0：两类关系在同一分支共存的程度高于这个条件基准。
- Delta 接近零：该统计没有显示额外的分支分配偏离。

这是相对分支机会的效应量，不是 p 值或 z-score。小样本下分配波动仍然存在，因此同时输入数量、覆盖率、有效分支数和适用标记，让学习器决定其权重。

当 S = 0、D = 0 或 M < 2 时，Delta 置零并标记为不适用，不能将其解释为没有结构组织。只有一个分支时 kappa_obs = kappa_0 = 1，没有跨分支分配信息，但其他强度和关系关联仍可使用。

为什么必须有随机基准：大分支天然更容易容纳一对 S/D。只看 sum(s_b d_b) 会把分支容量与立场组织混合在一起。这个基准固定无符号传播拓扑和局部总量，刻意允许各分支的 S/D 分配变化；若又固定每个分支的 s_b、d_b，该统计就不再能变化。它回答的是明确的局部分配问题，不声称全面控制所有有符号度偏好。

**6. 一个可验证的区分例子**

v 有两条直接回复分支 u1/u2，两条首边标签都为 S，每个 u 都有两个回复。两图的无符号树、第一层 S/D 数量、第二层 S/D 数量和 SS/SD/DS/DD 数量完全相同。

```text
A：不同分支分别集中一种关系     B：各分支都包含两种关系
v                              v
├─S→ u1                        ├─S→ u1
│    ├─S→ a                    │    ├─S→ a
│    └─S→ b                    │    └─D→ b
└─S→ u2                        └─S→ u2
     ├─D→ c                         ├─S→ c
     └─D→ d                         └─D→ d
```

两图在 k = 2 都有 S = 2、D = 2、SS = 2、SD = 2。T 的首边只有 S 类，因此 T 的条件残差也相同且为零。

但是 A 的 (s_b,d_b) 为 (2,0)、(0,2)，B 为 (1,1)、(1,1)。共同基准 kappa_0 = 1/3，A 的 Delta = 1/3，B 的 Delta = -1/6。该分支统计能区分强度、层次分布和简单路径总计数都相同的局部结构。

这个例子证明的是相对于上述统计基线的额外区分能力，不是完整图同构识别能力，也不是超越带标签 GIN/1-WL 的证明。

**7. 可训练的节点结构模块**

除了解析统计，增加共享的分支编码器来学习分支量和首边关系之间的非线性组合。分支输入包括：首边 S/D/unknown 的 one-hot、log(1+s_b)、log(1+d_b)、log(1+m_b)、相对总体的支持比例偏离，以及尺度 embedding。比例偏离可以使用：

\[
e_b = (s_b - m_b S/M)/(m_b+1),\qquad M>0.
\]

共享 MLP 把每个分支编码为向量，对 m_b > 0 的分支取均值，并保留有效分支数。没有有效分支时使用零向量和有效性标记。分支没有固定 ID embedding，也不按节点编号排序。

每个尺度的 token 使用：

\[
t_v^{(k)} = F_{scale}([\rho_v^{(k)},\operatorname{vec}(T/M_{pair}),
\operatorname{vec}(R),\Delta_v^{(k)},g_v^{(k)},\text{counts, masks}]) + E_{hop}(k).
\]

g 为共享分支 MLP 的置换不变池化结果。k = 1 的分支输入可直接用首边 one-hot 得到 s_b/d_b，关系矩阵和跨分支偏离量标记为不适用。

位置/角色向量 p_v 单独编码：root/support父帖/deny父帖/unknown、log(1+深度)、log(1+事件大小)，以及根不可达标记。非根孤立节点不能伪装成根。

使用一个始终有效的角色 token t^(0)，避免所有尺度为空时 softmax 无效。对有效的尺度 token 进行学习加权：

\[
\alpha_{vk}=\operatorname{softmax}_{k}(q(p_v)^T W t_v^{(k)}),
\quad h_v^{structure}=F_{out}([p_v,\sum_{k=0}^{K}\alpha_{vk}t_v^{(k)},
\rho_v^{(1)}\Vert\cdots\Vert\rho_v^{(K)}]).
\]

原始多尺度强度描述量仍提供给输出层，避免全部信息只通过一个加权和。随后把 h_structure 作为现有 GIN 的初始节点向量。编码器参数通过事件分类目标端到端更新，不需要新增预训练。

所有分支池化、计数和角色处理均不依赖任意节点编号，因此模块对节点重排具有等变性。它在标记树上的区分范围需要单独研究，不承诺区分所有树或所有带标签图。

**8. 计算与 DIGNN 接口**

建议新增独立类 StanceStructureEncoder，输入 directed_edge_index、与其逐列匹配的 directed_edge_stance、batch、roots、sizes；输出 nodes [N,H]、确定性 descriptors、diagnostics。确定性描述量可以在图构建时缓存，也可以在 forward 中计算。

多尺度数量只需要 gather 和 index_add/scatter。每个 v → u 的分支量从 u 的前一尺度数量中读取。T、kappa 分子、容量基准和共享分支池化均可沿边计算。固定 K 时统计部分为 O(K(N+E))，无需枚举所有 S/D 路径、节点对或稠密 NxN 矩阵。神经分支编码还增加普通 MLP 的通道计算成本；不能把完整网络成本简单声称为与 H 无关的 O(KE)。

在 model/DIGNN.py 中，将六维构造和固定 Linear(6,H) 的输入部分替换为该编码器，保留残差 GIN、事件读出、文本 MLP、视图融合和训练接口。第一轮实验保留现有无向 GIN；结构特征构造始终使用有向传播边。方向化 GIN 可作为后续独立消融。

若启用结构重建，应重建停止梯度的确定性描述量，而不是可训练的 h_structure。无效比例/矩阵项应采用对应掩码，避免大量无效零目标主导重建。先按当前基础配置保持辅助权重为零比较结构模块，再单独研究重建与 HSIC。

当前 _inputs() 会删除自环、合并并排序重复边。接入时必须同步处理标签，不能把新边序列与旧标签拼接。新缓存优先成对使用 directed_edge_index/directed_edge_stance；旧无向缓存若没有可信方向，不应静默当作父 → 子树。出现重复边标签冲突应明确报错或记录为 unknown。

该设计假定有向根树/森林中的唯一父路径。多父 DAG 或含环图中，上述递推会变成路径/游走计数，应另行定义，不能继续解释成互不重叠的后代分支。

局部零模型公式适用于有效硬标签的位置置换。若引入连续置信度或软标签，需要重新定义加权分支机会基准，不能直接套用整数容量的有限总体公式。

**9. 最小验证方案与贡献边界**

必须比较：原六维 DIGNN；多尺度 S/D 强度；强度加普通 SS/SD/DS/DD；未校正的分支池化；加入条件关系残差和分支 Delta 的完整模块。模块比较应控制 GIN 层数和参数规模，并报告计算成本。

关键消融是去除 Delta、去除关系残差 R、去除共享分支 MLP、K = 1/2/3，以及角色/位置编码的单独作用。保留尺度总量的标签位置扰动，可以测试预测是否依赖立场的空间组织。它是机制诊断，不预设任何扰动都应降低性能，也不把所有扰动图强制当作对比学习负样本。

合成验证应包含第 6 节的配对树，并补充相同局部结构在无关节点置换后的输出一致性、随机条件置换下 Delta/R 的平均值接近零、叶节点/单节点图/缺失标签/单分支的有限输出。真实数据报告多个种子的宏 F1、精确率/召回率、运行成本和参数量；逐节点可视化结构分数时避免将其解释为命题真伪。

可主张的候选贡献是：针对父相对立场的传播树，构造分支条件化、多尺度、拓扑机会校正的节点结构表示，并证明它补充了总量和简单路径计数遗漏的分支组织信息。attention、MLP、S/D 度数、随机基准、一般模体计数都已有研究基础，不能分别声称为首创。是否构成足够的方法创新，需要更全面的相近工作核查和上述实证支持。

本次数学核对：在分支容量 (2,2)、(1,3)、(1,1,2)、(2,3,1)、(1,1)、(4) 下，按固定支持总量穷举了 18 个条件设置中的 120 种有效标签分配；kappa_obs 的条件均值与 kappa_0 一致，记录的最大绝对误差为 0。配对例子的分离偏离量分别为 1/3、-1/6。这不是模型性能验证。
